\# YATESLAB Enterprise Network Lab



\## Project Overview

This project documents the design, configuration, security, and testing of a simulated enterprise network using Cisco Packet Tracer.



\*\*Status:\*\* In progress



\## Objectives

\- Design a segmented enterprise network

\- Configure VLANs and trunk connections

\- Implement inter-VLAN routing

\- Configure DHCP and IP addressing

\- Apply access control lists (ACLs)

\- Test connectivity and troubleshoot issues



\## Technologies

\- Cisco Packet Tracer

\- Cisco IOS

\- VLANs and 802.1Q

\- IPv4 subnetting

\- DHCP

\- Access Control Lists
